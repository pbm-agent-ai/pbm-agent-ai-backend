# Test 스타일 가이드

## 목적
- 기능 추가 시 테스트를 함께 작성하는 문화를 유지한다.

## 기본 규칙
- 기능 코드 변경 시 관련 테스트를 함께 수정/추가한다.
- 테스트 이름은 한글로 의도를 드러낸다.
- 단위 테스트와 통합 테스트를 목적에 맞게 구분한다.

## 작성 원칙
- 정상 흐름, 경계값, 예외 흐름을 최소 1개 이상 고려
- Mock 사용 시 무엇을 검증하는지 분명히 한다.
- 테스트는 구현 세부보다 동작 계약을 검증한다.

## 금지 사항
- 테스트 없이 기능만 추가하지 않음
- 불필요하게 과한 통합 테스트만 작성하지 않음
