# Domain 스타일 가이드

## 목적
- Entity와 도메인 객체를 저장 구조와 도메인 의미가 드러나게 작성한다.

## 기본 규칙
- JPA Entity는 `domain/` 패키지에 둔다.
- 필드 의미가 드러나는 한국어 주석을 추가한다.
- 생성은 정적 팩토리 메서드를 우선 고려한다.
- 상태 변경은 의미 있는 메서드로 노출한다.

## 작성 원칙
- 무분별한 public setter를 피한다.
- 필수값은 생성 시점에 보장한다.
- DB 컬럼명과 제약조건이 드러나게 매핑한다.

## 금지 사항
- Entity를 단순 데이터 덩어리처럼 아무 곳에서나 수정하지 않음
- API 응답용 직렬화 모델로 직접 노출하지 않음
