토픽 발행자 소비자 이벤트 타입 목적
price-topic command price PRICE_CHECK_REQUEST, URL_MONITOR_REQUEST 가격 확인 요청 / URL 모니터링 구독 생성
product-selection-required price command PRODUCT_SELECTION_REQUIRED 검색 결과 후보 상품 목록 전달 (최대 30건)
product-selection command price PRODUCT_SELECTED 사용자가 선택한 상품 → 단건 재조회 + 가격 검증
price-validation-result price command PRICE_VALIDATION_COMPLETED, MONITORING_TRIGGERED_BROWSER_PURCHASE 검증 완료 → AgentRun 생성 / 모니터링 등록
price-alert price notification PRICE_ALERT 목표 가격 도달 → 텔레그램/이메일 알림 발송
payment-topic price payment PAYMENT_REQUESTED AUTO_PURCHASE 조건 충족 → PBM 블록체인 결제
session-key-registration price payment SESSION_KEY_REGISTRATION AI 에이전트 세션키 블록체인 등록 (addSessionKey)
subscription-termination price payment SUBSCRIPTION_TERMINATED 구독 취소(revoke)/만료(expire) 세션키 정리
